# TaskFlow — Personal Task Management Dashboard

TaskFlow is a modern and responsive task management dashboard built using **HTML, CSS, and JavaScript**.

It helps users create, organize, track, and manage daily tasks with features such as priorities, categories, due dates, search, filtering, progress tracking, dark mode, and local data persistence.

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Open the project folder.

3. Open `index.html` in a web browser.

No backend or installation is required.

## 💾 Data Persistence

TaskFlow uses the browser's **LocalStorage API** to store tasks.

Tasks remain available after refreshing or reopening the browser on the same device and browser.
